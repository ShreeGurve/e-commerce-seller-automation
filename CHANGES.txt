FLOW
  Return inspection marks 'claim eligible' -> Claims page lists it under 'Returns marked claim eligible' -> Create claim.
  Pre-filled: channel, order, return, product, type (Amazon = SAFE-T, Flipkart = Flipkart claim, otherwise damaged / missing / wrong item)
  and amount (price of the units that did not come back sellable). Everything is editable.
  Draft -> (you file it on the Amazon / Flipkart portal) -> Submitted -> Under review -> Approved / Partially approved / Rejected
  Rejected or partial -> Appeal -> decision again.  Closed ends it.  Nothing is ever sent to a marketplace by this system.
  Evidence: upload photos, videos, PDFs, or copy the photos taken at return inspection in one click. Files are private.
  Same order + same claim type cannot be opened twice while the first is not closed. A portal claim id can only be tracked once.

DEADLINES
  New claims get deadline = return date + 'Claim filing window' (Settings, default 30 days), editable per claim.
  Alerts apply to claims you still have to file (Draft) or appeal (Rejected / Partial / Appeal):
    URGENT at or under 'urgent' days (default 3)  |  WARNING at or under 'warning' days (default 7)  |  EXPIRED when past.
  Shown on: Claims list, claim page, Dashboard card, red badge on the sidebar Claims item.
  (Scheduled e-mail / WhatsApp reminders come with the notification system.)

MONEY
  Approved amount counts as RECOVERY in order profit (estimated and actual) as soon as it is approved.
  When the real payout shows up in a settlement (a reimbursement line) the payout replaces the claim amount: never counted twice.
  Reconciliation adds 'Approved claim not paid' when an approved claim has no reimbursement in any settlement after the wait days.

VERIFY
  1 Inspect a return, tick 'claim eligible'. Claims page shows it under suggestions. Create claim: type, amount, deadline are pre-filled.
  2 Claim page: upload a photo (or copy from the return). Mark Submitted (portal id optional).
  3 Mark Partially approved with an amount: Approved / Rejected figures update; order Profit card shows the recovery.
  4 Reject another claim, press Appeal with a new deadline. Timeline shows every step.
  5 Set a deadline 2 days away on a draft: Claims list, Dashboard and the sidebar badge turn red.
  6 Settings: change the urgent / warning days and see the flags move.
