WHAT YOU SEE  (Pricing in the sidebar; pick the channel at the top)
  Per product: price now, unit cost, fees, ad cost per unit, return cost per unit, BREAK-EVEN price, MINIMUM price, TARGET price,
  margin now, MAX DISCOUNT you can give before hitting the minimum, and how you compare with the lowest competitor.
  Status: Losing money / Fees too high / Below minimum / Below target / No price set / OK. Worst first.
  Click a product: a line-by-line breakdown of one unit's money, a WHAT-IF box ('what if I sell at 249?'), price history with chart, competitors with chart.

HOW THE PRICES ARE WORKED OUT (nothing guessed)
  profit per unit = price / (1 + GST)  -  unit cost  -  marketplace fees  -  ad cost per unit  -  return cost per unit
  - Fees: your fee rules (percentage + fixed + GST on fees). Fees are a straight line in price, so each target price is solved exactly,
    then rounded UP to the next whole rupee (the lowest whole-rupee price that really reaches the margin).
  - Unit cost: current COGS + packaging + other (cost history).
  - Ad cost and return cost per unit: averages of your own recent orders (Settings: look-back days, default 90). No orders yet = Rs 0, shown as '-'.
  - Minimum margin (Settings, default 5%) and Target margin (Settings > target profit margin, default 20%) set the minimum and target prices.
  - 'Current price' = the latest price you RECORDED for that channel, else the product's master selling price.
  If no fee rules exist for a channel the page says so: without fees every price looks better than it is.

PRICE HISTORY / COMPETITORS
  'Record price' keeps a dated history (with the previous price) of what you set. It does NOT change anything on Amazon / Flipkart.
  Competitor prices: type them in, or import them (Imports > Competitor prices: SKU, competitor, price, date). Same day + same competitor updates the price.
  Only prices captured in the last N days (Settings, default 30) are compared. This system never scrapes marketplaces.

VERIFY
  1 Make sure Fee rules exist for the channel (Finance > Fee rules). Open Pricing and pick the channel.
  2 Open a product: check the breakdown matches your own calculator. Try a what-if price below break-even: it turns red.
  3 Record a new price; the history shows 'was Rs X'. The status updates.
  4 Add two competitor prices. 'vs competitor' shows how far above / below you are.
  5 Place or import some orders with ad spend: ads / unit and returns / unit fill in and the break-even price rises.
