LISTINGS
  Write title, bullets, description, backend search terms, special features, A+ text, image count / video, brand, category.
  EVERY save is a new version (v1, v2, v3 ...). Saving identical text is refused. Restore copies an old version into a NEW version, history is never lost.
  Compare any two versions side by side: removed words red, added words green, plus the score change.
  'Mark live' only records which version you applied on the marketplace. NOTHING is ever sent to Amazon or Flipkart. A 'newer draft' tag shows when the latest version is not the live one.

SCORE (0-100)  Listings > Score rules (sliders icon)
  Title 20 | Bullets 20 | Keyword coverage 15 | Images 15 | Description 10 | A+ 10 | Special features 5 | Backend search terms 5   (all editable, can be switched off)
  The score is earned points / total max x 100, so weights never have to add up to 100.
  Rules you can change: title min / max length and 'keyword in first N characters', bullet count and length, description length, image target, A+ length,
  feature target, backend byte range. Every criterion shows tips (e.g. 'Move a primary keyword into the first 80 characters').
  Keyword checks use the keywords saved for that product + channel (primary count double). AEO / SEO / GEO keywords are tracked but not scored.
  After changing keywords or rules press 'Recalculate score' on a listing.
  The default limits (title 80-200, 5 bullets of 100-500, backend 150-250 bytes) are starting points: set them to your marketplace's current rules.

KEYWORDS
  Add many at once (one per line) with type, volume, competition, group. Types: Primary, Secondary, Long-tail, Backend, AEO, SEO, GEO.
  Rank history per keyword (organic / sponsored) with a chart. Group keywords. Import a file: Imports > 'Keywords (and rankings)'
  (columns: SKU, keyword, type, volume, competition, relevance, rank, rank date, source, group). Re-importing never duplicates; a changed volume / rank updates the row.

VERIFY
  1 Keywords > add 3 primary / secondary keywords for a product.
  2 Listings > New listing for that product and channel: write copy, Save. Read the score tips.
  3 Edit, improve the title, save: v2 appears. Compare v1 and v2: changes are highlighted, score goes up.
  4 Mark v2 live. Edit again: list shows 'newer draft'.
  5 Listings > sliders icon: change Title max points, save, Recalculate score.
  6 Product page > Listings and Keywords tabs show the summary.
